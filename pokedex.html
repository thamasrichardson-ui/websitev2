Pokédex App

Now I don't have to go catch 'em all.

Project Details

  • Date Completed: Nov. 2025
  • Project Role: AI Prompt Engineer
  • Software Used: Claude.ai
  • Type of Work: Proof-of-Concept Application
  • Nature of Work: AI-Accelerated Hackathon Challenge
  • Time to Complete: 30 minutes

You can view this project by clicking the image above!

Context

This project was executed during a Pokémon-themed Hacklahoma event following a presentation on AI-Accelerated Development "Vibe Coding" led by Dr. Anindya Maiti. The challenge was to rapidly create a functional, themed application in just 30 minutes. This exercise provided an opportunity to immediately apply principles of effective LLM prompting and demonstrate the speed of AI-driven prototyping.

Approach

I initiated the project by using precise, structured prompts focused on HTML and CSS, leveraging my foundational knowledge for rapid generation. A key challenge encountered was the live rendering issue with external image sprites within Claude's web environment. This issue required on-site troubleshooting, and the hypothesis was that the issue was browser-related. I later resolved the problem by downloading the code and running it locally, which proved that the underlying code was functional despite the rendering error.

Outcome

This successful prototype features the 251 Pokémon from the Kanto and Johto regions. Key functional features include:

  • A robust search functionality allowing users to query by Pokémon name or Pokédex number.
  • Intuitive site navigation with back, forward, and randomize buttons for content discovery.
